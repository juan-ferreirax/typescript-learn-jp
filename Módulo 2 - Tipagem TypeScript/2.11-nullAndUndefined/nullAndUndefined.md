# Null vs Undefined

| Null | Undefined |
| --- | --- |
| Pode ser atribuído a uma variável, porém não aponta para nenhum objeto. | Declara uma variável, porém ainda não atribui um valor. |
| É um objeto. | É um tipo. |
| O valor de null é primitivo, mas representa referência nula, vazia ou inexistente. | O valor de undefined é primitivo e costuma aparecer quando uma variável foi declarada, mas não recebeu valor. |
| Null indica ausência de um valor para uma variável. | Undefined indica ausência do valor da própria variável. |
| Null é convertido em 0 (zero) durante a execução de operações primitivas. | Undefined é convertido em NaN (Not a Number) durante a execução de operações primitivas. |
